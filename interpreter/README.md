# Interpreter

LIRA-driven generator of a simple C++ interpreter.

**Layout:**

- [Target](Target) — target-specific implementation details.
- [runtime](runtime) — static C++ runtime
- [templates](templates) — Jinja2 templates for `execute.hh/cc` and `cpu_state.hh/cc`

The interpreter generator produces `execute.hh/cc` and `cpu_state.hh/cc`.
It consumes the LIRA IR directly; the decoder, snippets and base operations
are generated by the sibling generators ([`decoder/`](../decoder),
`cpp.snippets`, `cpp.base_ops`). The [`encoder/`](../encoder) generator is
independent and is not part of the interpreter build.

## Build

From the repository root:

```bash
cmake --preset Default-Release [OPTIONS]
cmake --build build/Default-Release --target gen-interp   # code generation
cmake --build build/Default-Release --target build-interp # simulator build
```

The generated interpreter sources and the interpreter binary are placed
into `build/Default-Release/interpreter` (override via `INTERP_OUT_DIR`);
the LIRA IR is generated into `build/Default-Release/lira_ir`.

## Options

| Option               | Default                             | Description                                               |
| -------------------- | ----------------------------------- | --------------------------------------------------------- |
| `ARCH_TARGET`      | *(required)*                      | Target architecture (interpreter `Target/${ARCH_TARGET}` package); set by the presets to `RISC_V` |
| `ARCH_SOURCE`      | *(required)*                      | Architecture description source (`Protea`, `ASL`); set by the presets to `Protea` |
| `INTERP_OUT_DIR`   | `${CMAKE_BINARY_DIR}/interpreter` | Directory for the generated interpreter sources and binary |
| `CMAKE_BUILD_TYPE` | via preset (`Release`)            | Build type (`Release` / `Debug` / `RelWithDebInfo`) |
